🛠 IT & Cloud Automation Portfolio
This repository contains a collection of projects designed to automate common IT tasks, analyze support data, and enforce cloud security. These projects demonstrate my proficiency in Python, SQL, and AWS, as well as my focus on Identity and Access Management (IAM) and Active Directory workflows.

1.  User Onboarding Automation Script
Objective: To automate the creation of user accounts and permission leveling to reduce manual entry errors and save time during the onboarding process.

How it works: Reads employee data from a CSV file and automatically assigns access levels based on the department.

Skills Demonstrated: Python Scripting, IAM Logic, Data Handling (CSV/JSON), and Helpdesk Workflow Automation.

Key File: onboard_users.py

2. Helpdesk Ticket Analysis Tool
Objective: To identify common technical trends and help IT departments prioritize resources based on issue frequency.

How it works: Uses SQL to query a database of mock support tickets, identifying which departments have the highest volume of issues like "Password Resets" or "VPN Issues."

Skills Demonstrated: SQL (SQLite), Data Analysis, Python, Problem Solving for IT Support.

Key File: ticket_analysis.py

3.  AWS Cloud & IAM Security Project
Objective: To deploy a secure cloud environment for hosting web assets while enforcing the "Principle of Least Privilege."

What I did: Configured an AWS S3 bucket and developed a custom IAM JSON Policy to restrict user access, ensuring authorized personnel can manage files but cannot delete the bucket.

Skills Demonstrated: AWS, Cloud Computing, IAM, JSON, Cybersecurity.

Key File: s3_iam_policy.json
