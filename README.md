1. User Onboarding Automation Script
Objective: To automate the creation of user accounts and permission leveling to reduce manual entry errors and save time during the onboarding process.

How it works: > * Reads employee data from a CSV file.

Automatically assigns Identity and Access Management (IAM) levels based on the department.

Simulates the workflow used in Active Directory environments.

Skills Demonstrated: Python Scripting, IAM Logic, Data Handling (CSV/JSON), and Helpdesk Workflow Automation.

2.Helpdesk Ticket Analysis Tool
Objective: To identify common technical trends and help IT departments prioritize resources based on issue frequency.

How it works:

Uses SQL to query a database of support tickets.

Categorizes issues by department and priority level.

Provides actionable insights into which systems (like login portals or hardware) need the most attention.

Skills Demonstrated: SQL, Data Analysis, Python, Problem Solving for IT Support.
